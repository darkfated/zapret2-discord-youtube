# zapret2-discord-youtube

Обход DPI для Discord, YouTube, игр, и другого. Выбрал режим - нажал **Старт**. Работает на движке zapret2 (winws2).

## Запуск

**Для пользователей** - скачайте последнюю версию из [Релизов](https://github.com/darkfated/zapret2-discord-youtube/releases/latest), распакуйте zip и запустите `zapret2-discord-youtube.exe`.

**Для разработчиков** - изменяйте содержимое и запускайте `build.bat`. В `dist/` появится готовое решение - папка `zapret2-discord-youtube/`.

## Использование

1. Выберите режим в списке слева (начните с **Изумруд 1** - базовый).
2. Нажмите **Старт**.
3. Не работает - перебирайте режимы. Жёлтые - агрессивные ("Уголь", "Метеорит"), могут задеть другой трафик.

Обход уже включен - клик по другому режиму сразу переключит его, для удобства.

## Режимы

Варианты сгруппированы по приёму обхода.

| Группа | Варианты | Приём |
|--------|----------|-------|
| Изумруд | 1-4 | Разбиение пакетов TLS (базовый) |
| Кобальт | 1-2 | Фейки + подмена меток времени |
| Алмаз | 1-3 | Подмена имени сайта в запросе |
| Рубин | 1-4 | Фейки + разбиение, усиленный QUIC |
| Аметист | - | Автоматический фейк TLS |
| Жемчуг | 1-5 | Только фейковые пакеты (мягкие) |
| Янтарь | - | Смешанные техники |
| Уголь | - | Весь трафик (агрессивный) |
| Метеорит | - | Экспериментальный |

## Настройка (для продвинутых)

Всё в текстовых файлах:

- `config/strategies.yaml` - параметры режимов
- `config/settings.yaml` - общие настройки
- `config/blobs.yaml` - образцы пакетов
- `lists/` - домены и IP (добавляйте и получайте доступ к сайтам)

Измените и перезапустите. Свой режим и доработки можно предлагать через [Pull Request](https://github.com/darkfated/zapret2-discord-youtube/pulls).
