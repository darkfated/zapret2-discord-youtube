# zapret2-discord-youtube

Обход DPI для Discord, YouTube и игр. Выбрал режим - нажал **Старт**. Работает на движке zapret2 (winws2).

## Запуск

**Для пользователей** - скачайте последнюю версию из [Релизов](https://github.com/darkfated/zapret2-discord-youtube/releases/latest), распакуйте zip и запустите `zapret2-discord-youtube.exe`.

**Для разработчиков** - изменяйте содержимое и запускайте `build.bat`. В `dist/` появится собранный пакет `zapret2-discord-youtube.zip`.

## Использование

1. Выберите режим (начните с **Изумруд** - базовый).
2. Нажмите **Старт**.
3. Не работает - перебирайте режимы. Жёлтые - агрессивные ("Уголь", "Метеорит"), могут задеть другой трафик.

## Режимы

Готовые комбинации приёмов обхода. Подбирайте под свою сеть.

| Режим | Когда |
|-------|-------|
| Изумруд | Базовый, большинству подходит |
| Кобальт | Если Изумруд не сработал |
| Алмаз | Строгие провайдеры |
| Рубин | YouTube и игры |
| Уголь | Упорные блокировки (весь трафик) |
| Метеорит | Экспериментальный, если прочие не помогли |

И ещё 16 режимов - в выпадающем списке.

## Настройка (для продвинутых)

Всё в текстовых файлах:

- `config/strategies.yaml` - параметры режимов
- `config/settings.yaml` - общие настройки (порты и т.д.)
- `config/blobs.yaml` - образцы пакетов
- `lists/` - домены и IP

Измените и перезапустите. Свой режим и доработки можно предложить через [Pull Request](https://github.com/darkfated/zapret2-discord-youtube/pulls).
